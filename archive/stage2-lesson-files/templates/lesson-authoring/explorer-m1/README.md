# Explorer M1 workbook fixtures

Bundled CSV exports of the Explorer Phase 1 spreadsheet columns. Used when the original `.xlsx` files are not on the authoring machine.

**Re-import:** `npm run lesson:import:explorer`

**Source workbooks (when available):**

- `Explorer M1 Lessons 1-4.xlsx` → `explorer-phase-1.csv`
- `NGA Academy Lesson Scaffold (3).xlsx` → `lesson-scaffold.csv`

Lessons 1–2 contain full Lars copy. Lessons 3–4 use placeholder game-archetype IDs until the detailed workbook is filled in.
